海岸线 · 使用说明

深圳沿海骑行规划与记录 · 移动端优先 · 当前版本：MVP Demo（2026-08-09）

一句话定位：一个能在手机上打开的网页 App，帮你规划深圳沿海骑行路线，并用 GPS 记录每次骑行的时长、轨迹和次数。数据存在你自己的手机里，不上传服务器。

底部有 4 个标签：规划记录历史我的。完整的使用循环就是「规划 → 骑行 → 回看」。

一、3 步快速上手

1
规划一条路线
在「规划」页点一条经典沿海路线卡片，或点「＋ 自定义规划路线」自己在地图上点起点、终点来生成路线。可选贴海或最短两种偏好。
2
开始骑行记录
在路线页点「开始骑行」进入「记录」页，点红色「开始骑行」按钮。手机会请求定位权限——授权后，地图会跟着你走，实时显示里程、计时和速度。
3
结束并回看
骑完点「结束骑行」，记录自动保存。到「历史」页能看每一次骑行的轨迹回放；到「我的」页能看累计次数、里程、时长和最快均速。
📌 每次骑行都需要授权定位权限，并且保持手机屏幕亮着（锁屏后 GPS 可能暂停）。信号差或忘开定位时，可在「历史」页用「手动补录」补救。

规划页（🗺️ 首页）

  • 经典沿海路线库：内置 4 条深圳沿海预设路线（深圳湾、盐田、大鹏、蛇口），卡片显示距离、预计用时与难度。
  • 地图预览：首页小地图会画出这些路线；首次打开会用高德骑行规划算出真实轨迹并缓存（规划失败则回退近似线）。
  • ＋ 自定义规划路线：进入规划页，在地图上点一下设起点、再点一下设终点，选「最短」或「沿海·骑行道优先」，点「规划」即可生成骑行路线与距离/用时。
  • 保存我的路线：预设详情或自定义规划结果都能「保存为我的路线」，存到规划页下方的「我的路线」列表。

记录页（🚴）

  • 实时 GPS 轨迹：点「开始骑行」后持续采集定位，地图实时跟随并画出红色轨迹。
  • 实时数据：里程（km）、计时、当前均速（km/h）随骑行更新。
  • 结束保存：点「结束骑行」自动算好并存入「历史」。从某条路线进入时，记录会关联该路线名称。
  • 手动补录（在「历史」页）：没开定位或信号差时，选一条预设路线 + 填骑行分钟数，照样能记一条记录。

历史页（📜）

  • 骑行列表：按时间倒序，显示路线名、日期、来源（GPS / 手动）、里程与时长。
  • 轨迹回放：点任意一条记录，地图展示那次骑行的完整轨迹和均速。

我的页（👤）

  • 统计看板：骑行次数、累计里程、累计时长、最快均速，以及「最长一次」记录。
  • 清空本地记录：一键清除全部数据（不可恢复）。
  • 数据说明：所有记录仅存于本机浏览器（IndexedDB），清除缓存会丢失，换设备不互通。

四、已知限制（用之前要知道）

  1. 没有"跟着走"的导航：规划好路线后，骑行时地图只是跟着你的 GPS 画轨迹，不会语音/箭头提示你该往哪拐。需要靠你自己看着地图骑。
  2. 数据只在当前手机：清缓存、换手机、用无痕模式都会丢记录，且无法在多设备间同步。
  3. 自定义"沿海"是软约束：自定义规划选「贴海」只是高德的一个路线偏好，不保证全程贴着海岸线；真正稳定的沿海路线是那 4 条预设。
  4. 需要定位与亮屏：锁屏或系统杀后台会中断记录；户外信号弱处漂移较大（已做基础处理，但未做专业滤波）。
  5. 高德 Key 写在网页里：个人 demo 阶段没问题，正式上线前需加域名白名单防盗刷（见 README）。

五、下一步可以做什么
